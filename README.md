# Design and Analysis of Algorithms

## Overview

This repository contains programs and implementations of various concepts from Design and Analysis of Algorithms (DAA) using C.

## Topics Covered

* Arrays
* Searching
* Sorting
* Recursion
* Divide and Conquer
* Greedy Algorithms
* Dynamic Programming
* Graph Algorithms
* Time and Space Complexity

## Requirements

* C Compiler
* GCC / MinGW / Code::Blocks / VS Code

## How to Run

gcc filename.c -o output
./output

## Purpose

This repository is created for learning and practicing different algorithms and understanding their time and space complexity.
